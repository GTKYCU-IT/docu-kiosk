# Issue tracker

Tickets are tracked in **GitHub Issues** on this repository (`GTKYCU-IT/docu-kiosk`), created with the `gh` CLI.

- `to-tickets` publishes one issue per ticket in dependency order (blockers first), each referencing its blocking issues in the "Blocked by" section.
- Triage skills read from and write to GitHub Issues.
- PRs as a request surface: **off** — do not pull open PRs into the triage queue.
