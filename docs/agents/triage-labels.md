# Triage labels

GitHub labels used by the triage workflow. Each label string equals its role name:

| Role | Label |
|---|---|
| New issues awaiting triage | `needs-triage` |
| Waiting on reporter/agent for info | `needs-info` |
| Agent-grabbable — blockers done, self-contained | `ready-for-agent` |
| Needs a human decision or action | `ready-for-human` |
| Explicitly declined | `wontfix` |
